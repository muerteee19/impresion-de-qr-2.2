# Sistema de tickets de compra

Aplicación web estática para agregar productos, calcular totales, generar tickets con código QR e imprimirlos.

## Uso

Abre `index.html` directamente en un navegador moderno. No requiere instalación, servidor ni proceso de compilación.

La lista de productos se conserva en `localStorage` del navegador. El código QR se carga desde CDN cuando hay conexión a Internet.
